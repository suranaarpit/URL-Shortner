# URL-Shortner

### Tech Stack: HTML, JavaScript, EJS, Node JS, Express, MongoDB, Tailwind CSS

### Steps to start application:
* Clone the repository.
* Open VS Code
* Install Dependencies
* Open Terminal
* Write npm run dev to start application
* At last enter the url which you want to short.
